=== two-sum
title: Two Sum
difficulty: easy
tags: array, hash-map
sig: twoSum(nums: int[], target: int) -> int[]
compare: unordered
--- description
You are given an integer array `nums` and an integer `target`. Find the two **different positions** whose values add up to `target` and return those two indices.

Each input has exactly one valid pair, and you may not use the same element twice. The indices can be returned in any order.

**Constraints**
- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i], target <= 10^9`

**Follow-up:** can you beat O(n²)?
--- tests
[[2,7,11,15], 9] => [0,1]
[[3,2,4], 6] => [1,2]
[[3,3], 6] => [0,1]
[[-1,-2,-3,-4,-5], -8]
[[0,4,3,0], 0]
[[1,5,9,13,2], 15]
[[1000000000,-999999993,5], 7]
--- python
class Solution:
    def twoSum(self, nums, target):
        seen = {}
        for i, x in enumerate(nums):
            if target - x in seen:
                return [seen[target - x], i]
            seen[x] = i
--- javascript
var twoSum = function(nums, target) {
    const seen = new Map();
    for (let i = 0; i < nums.length; i++) {
        if (seen.has(target - nums[i])) return [seen.get(target - nums[i]), i];
        seen.set(nums[i], i);
    }
};

=== valid-palindrome-ii
title: Valid Palindrome II
difficulty: easy
tags: string, two-pointers, greedy
sig: validPalindrome(s: str) -> bool
--- description
Given a string `s`, return `true` if it is already a palindrome or can become one by deleting **at most one** character. Otherwise return `false`.

**Constraints**
- `1 <= s.length <= 10^5`
- `s` contains lowercase English letters only.
--- tests
["aba"] => true
["abca"] => true
["abc"] => false
["deeee"]
["eeeed"]
["ebcbbececabbacecbbcbe"]
["cbbcc"]
["abcdba"]
["abccbxa"]
--- python
class Solution:
    def validPalindrome(self, s):
        def pal(i, j):
            while i < j:
                if s[i] != s[j]:
                    return False
                i += 1; j -= 1
            return True
        i, j = 0, len(s) - 1
        while i < j:
            if s[i] != s[j]:
                return pal(i + 1, j) or pal(i, j - 1)
            i += 1; j -= 1
        return True
--- javascript
var validPalindrome = function(s) {
    const pal = (i, j) => { while (i < j) { if (s[i] !== s[j]) return false; i++; j--; } return true; };
    let i = 0, j = s.length - 1;
    while (i < j) {
        if (s[i] !== s[j]) return pal(i + 1, j) || pal(i, j - 1);
        i++; j--;
    }
    return true;
};

You get an integer array `nums` sorted in non-decreasing order. Remove the repeated values **in place** so each distinct value appears once, keeping their original relative order. Return `k`, the number of distinct values.

After your function returns, the first `k` slots of `nums` must hold the distinct values in order. Whatever is left beyond index `k - 1` does not matter. The judge checks `nums[0..k-1]`.

Use O(1) extra memory.

**Constraints**

- `-100 <= nums[i] <= 100`
--- tests
[[1,1,2]] => [1,2]
[[0,0,1,1,1,2,2,3,3,4]] => [0,1,2,3,4]

class Solution:
    def removeDuplicates(self, nums):
        k = 1
        for i in range(1, len(nums)):
            if nums[i] != nums[k - 1]:
                nums[k] = nums[i]; k += 1
        return k

var removeDuplicates = function(nums) {
    let k = 1;

class Solution:

class Solution:
    def search(self, nums, target):
        lo, hi = 0, len(nums) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid] == target:

            if nums[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return -1

var validWordAbbreviation = function(word, abbr) {
    let i = 0, j = 0;
    while (i < word.length && j < abbr.length) {
        if (abbr[j] >= '0' && abbr[j] <= '9') {
            if (abbr[j] === '0') return false;
            let n = 0;
            while (j < abbr.length && abbr[j] >= '0' && abbr[j] <= '9') n = n * 10 + Number(abbr[j++]);
            i += n;
        } else {
            if (word[i] !== abbr[j]) return false;
            i++; j++;
        }
    }
    return i === word.length && j === abbr.length;
};

    def __init__(self):
        self.inn, self.out = [], []
    def push(self, x):
        self.inn.append(x)

            while self.inn:
                self.out.append(self.inn.pop())
    def pop(self):

class Solution:
    def merge(self, nums1, m, nums2, n):
        i, j, k = m - 1, n - 1, m + n - 1
        while j >= 0:
            if i >= 0 and nums1[i] > nums2[j]:
                nums1[k] = nums1[i]; i -= 1
            else:
                nums1[k] = nums2[j]; j -= 1

**Hint:** use the BST ordering to walk a single path instead of visiting every node.
--- tests

[[1], 4.428571] => 1
[[4,2,5,1,3], 3.5] => 3
[[10,5,15,2,7,null,20], 6]

class Solution:
    def closestValue(self, root, target):
        best = root.val
        while root:
            if abs(root.val - target) < abs(best - target) or (abs(root.val - target) == abs(best - target) and root.val < best):
                best = root.val
            root = root.left if target < root.val else root.right
        return best

    let best = root.val;

        const d = Math.abs(root.val - target), bd = Math.abs(best - target);

        root = target < root.val ? root.left : root.right;
    }
    return best;
};

        rank = {c: i for i, c in enumerate(order)}

var isAlienSorted = function(words, order) {
    const rank = {};
    for (let i = 0; i < 26; i++) rank[order[i]] = i;
    for (let i = 0; i + 1 < words.length; i++) {
        const a = words[i], b = words[i + 1];
        let j = 0;
        while (j < a.length && j < b.length && a[j] === b[j]) j++;
        if (j === b.length && j < a.length) return false;
        if (j < a.length && rank[a[j]] > rank[b[j]]) return false;
    }
    return true;
};
